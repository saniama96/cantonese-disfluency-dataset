# # Cantonese Casual Conversation Disfluency Dataset

## Abstract
This dataset contains 60 minutes of natural Cantonese conversations annotated with three disfluency tags: filled pauses [FIL], repairs [REP], and false starts [FS]. The data was collected from four native Cantonese speakers in casual settings. This is the first publicly available resource for disfluency analysis in Cantonese conversational speech.

## File Structure
- raw_audio/ - Original recordings
- transcripts/ - Corrected transcripts
- annotations/ - CSV files with timestamps and tags
- docs/ - Annotation guidelines and agreement comparison

## Annotation Tags
| Tag | Meaning | Example |
|-----|---------|---------|
| [FIL] | Filled pause | 我 [FIL] 想去 |
| [REP] | Repair | 我尋晚 [REP] 我尋晚做報告 |
| [FS] | False start | 我要 [FS] 我想食飯 |
